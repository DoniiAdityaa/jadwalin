# 🎓 Smart Student Rundown & AI Schedule (Flutter)

Aplikasi pengatur jadwal pribadi khusus mahasiswa aktif dan organisatoris. Dirancang dengan konsep **Daily Rundown per Sesi (Time-Blocking)** dan dilengkapi **AI Multi-Input (Gemini API)** untuk mengekstrak jadwal otomatis dari dokumen PDF, gambar/screenshot, maupun teks pengumuman chat tanpa perlu input manual.

---

## ✨ 1. Fitur Utama (Core Features)

1. **Multi-Source AI Importer (PDF, Gambar/SS, Teks Chat)**
   - Ekstraksi jadwal otomatis dari PDF KRS/Jadwal UTS-UAS, poster kegiatan, atau *copy-paste* chat grup organisasi (WA/Discord).
   - Mendukung **Semester Setup**: Sekali *upload* KRS di awal semester, sistem otomatis men-generate jadwal matkul berulang selama 16 minggu ke depan.
2. **Student Daily Rundown (Tampilan Per Sesi & Per Divisi/Sie)**
   - Jadwal harian dibagi otomatis ke dalam 4 sesi waktu: **Sesi Pagi**, **Sesi Siang**, **Sesi Sore**, dan **Sesi Malam**.
   - Dilengkapi penanda kategori & peran spesifik: `[KULIAH]`, `[UJIAN]`, `[ORG - Nama Divisi/Sie]`, `[BOOTCAMP]`, serta blok otomatis untuk `[JEDA / TRANSISI]` dan `[KOSONG / FREE]`.
3. **Smart Conflict & Buffer Detector**
   - **Hard Conflict (Merah):** Peringatan otomatis jika jadwal rapat/organisasi bertabrakan langsung dengan jam kuliah.
   - **Buffer Warning (Kuning):** Peringatan jika jeda antar kegiatan kurang dari 30 menit (rawan terlambat pindah gedung/lokasi).
4. **AI Quick Reschedule & "Copy Free Slots"**
   - Fitur asisten chat untuk menanyakan slot waktu luang di minggu tertentu.
   - Tombol sekali klik untuk menyalin daftar jam kosong dengan format rapi yang siap dikirim ke grup WhatsApp/Discord organisasi.
5. **Dual Local Notification System**
   - **Briefing Malam (H-1 jam 20:00 WIB):** Rangkuman seluruh agenda untuk keesokan harinya per sesi.
   - **Reminder Hari-H (H-1 Jam):** Pengingat sebelum kegiatan dimulai lengkap dengan informasi ruangan/lokasi/link rapat.
6. **Offline-First & No-Login Setup**
   - Seluruh data jadwal disimpan di dalam database lokal HP (SQLite / Isar) agar cepat, responsif, dan hemat kuota.
   - Hanya membutuhkan input Nama Panggilan & Nama Kampus saat pertama kali membuka aplikasi.

## ⚙️ 3. Logika Sistem di Balik Layar (Core System Rules)

1. **Aturan Pembagian Sesi Otomatis (`session_time`):**
   - `05:00 - 11:59` -> **Sesi Pagi**
   - `12:00 - 14:59` -> **Sesi Siang**
   - `15:00 - 17:59` -> **Sesi Sore**
   - `18:00 - 23:59` -> **Sesi Malam**
2. **Aturan Default Durasi AI:**
   - Jika input chat/dokumen hanya menyebutkan jam mulai tanpa jam selesai (contoh: *"Rapat jam 19.00"*), AI otomatis mengatur durasi *default* selama **2 jam** (`19:00 - 21:00`).
3. **Aturan Jadwal Berulang (Recurring KRS):**
   - Jika `is_recurring == true`, sistem melakukan *looping* penyimpanan sebanyak **16 minggu ke depan** sebagai baris data terpisah di database lokal agar mudah diedit per tanggal jika sewaktu-waktu ada kelas pengganti.
4. **Rumus Deteksi Bentrok:**
   - **Hard Conflict (Merah):** `(Start_Baru < End_Lama) && (End_Baru > Start_Lama)`
   - **Buffer Warning (Kuning):** Selisih antara `End_Lama` dan `Start_Baru` kurang dari **30 menit**.

## 🗄️ 4. Skema Database Lokal (`schedules` Table)

| Nama Kolom | Tipe Data | Keterangan |
| :--- | :--- | :--- |
| `id` | `INTEGER` (PK) | ID unik setiap jadwal (Auto Increment) |
| `title` | `TEXT` | Nama matkul / agenda rapat / kegiatan |
| `category` | `TEXT` | `'Kuliah'`, `'Ujian'`, `'Organisasi'`, `'Bootcamp'`, `'Pribadi'` |
| `role_or_sie` | `TEXT` (Nullable) | Nama divisi/sie (Contoh: `'Div. IPTEK'`, `'Sie Acara'`, atau kosong jika kuliah) |
| `date` | `TEXT` | Tanggal kegiatan dalam format `YYYY-MM-DD` |
| `session` | `TEXT` | `'Pagi'`, `'Siang'`, `'Sore'`, `'Malam'` (Di-set otomatis dari `start_time`) |
| `start_time` | `TEXT` | Jam mulai dalam format `HH:MM` (24 jam) |
| `end_time` | `TEXT` | Jam selesai dalam format `HH:MM` (24 jam) |
| `location` | `TEXT` (Nullable) | Ruang kelas, nama kafe, atau link Google Meet / Discord |
| `is_recurring` | `INTEGER` (Bool) | `1` jika jadwal rutin mingguan, `0` jika sekali jalan |

## 🛠️ 5. Struktur Folder & Tech Stack Flutter

### Packages Utama (`pubspec.yaml`):
- `sqflite` & `path`: Penyimpanan database lokal SQLite.
- `shared_preferences`: Menyimpan data profil mahasiswa (Nama & Kampus).
- `google_generative_ai`: Integrasi Gemini API untuk ekstraksi PDF/Gambar/Teks & fitur AI Chat.
- `file_picker` & `image_picker`: Mengambil file PDF dan *screenshot* dari penyimpanan HP.
- `table_calendar`: Komponen kalender interaktif.
- `flutter_local_notifications`: Penjadwalan alarm notifikasi H-1 malam & H-1 jam.
- `provider`: *State management* aplikasi.

### Struktur Direktori (`lib/`):
```text

├── main.dart
├── models/
│   └── schedule_model.dart       # Model data & konversi JSON/Map SQLite
├── services/

│   ├── ai_service.dart           # Prompt Gemini API (Ekstraksi JSON & AI Chat)
```
